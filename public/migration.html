GeeFox Git Utility
Repository Migration

Move your app into app/

This tool performs a repository-level migration from your phone. It scans the current branch, lets you choose exactly what belongs inside app/, previews the change, then creates one Git commit using the Git data API.

Your existing GeeFox session is used. No GitHub token is entered into this page.
The migration is performed against the selected branch. A new commit is created; existing file blobs are reused.

Important deployment note
If your repository contains a root-level api/ directory for Vercel/server functions, keep it outside app/ unless your deployment architecture is intentionally configured to move it. This tool does not force you to move anything.

Confirm repository migration

This operation creates a new commit that adds the selected content under the destination and removes the old root paths. It is designed to preserve the existing Git blobs, but it is still a real repository change.
